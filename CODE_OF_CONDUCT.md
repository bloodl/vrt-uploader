# Code of conduct

This is a small project by raiders, for raiders. The rules are the ones a decent guild runs on.

- **Be civil.** Disagree with the code, not the person. No insults, no harassment, no slurs, in issues, pull
  requests or anywhere this project is discussed.
- **Assume good faith.** A wrong report or a clumsy patch is a favour, not an attack. Answer it as one.
- **Keep other people's data out of it.** Do not paste loot histories, guild rosters, upload codes or settings
  files into issues. Describe the problem; the maintainer will ask for what is needed.
- **Security problems go through [SECURITY.md](SECURITY.md)**, not a public issue.

The maintainer, Furytann, decides what is out of line and may edit, lock or remove contributions and block
people who keep at it. That decision is final for this project.
